---
name: create-spec-style
description: Apply the user's conventions for requirements, background, and acceptance criteria only when creating a new spec, not when editing or reviewing an existing spec.
---

Create a Lightweight Specification that describes, from the user's perspective, the problem to solve, goals and non-goals, concrete requirements, and verifiable acceptance criteria. Clarify material ambiguities with the user and record the conclusions. Keep the length proportional to the task's complexity and choose an appropriate structure.
