# 启动模板

需要用户提供运行配置时读取。保留用户已给出的值，省略项按 [入口](../SKILL.md#1-确认计划) 推导，不为可推导项重复提问。

```text
$ticket-queue

仓库：<路径>
目标分支／现有 PR：<分支与链接>
票源与范围：<目录或 GitHub 筛选，包含与排除的票>
模式：<串行，或并发上限 N>
执行／诊断模型：<模型>
备用执行模型：<模型>
本次授权：<提交、推送、远端票据更新的范围>

先给出执行顺序或并发轮次，等我确认再开始。
```

只有需要覆盖默认值时，补充角色配置、记录路径、检查间隔或预期 HEAD。启动请求用于规划；实际派工使用对应步骤中的任务模板。
