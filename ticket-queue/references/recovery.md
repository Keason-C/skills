# 恢复会话

仅在续接、运行故障或中断恢复时读取。先查运行日志、存活进程、worktree 与 Git 状态，确认哪个角色仍拥有写入权。

正常续接使用准确的 session/thread ID，在该角色已登记目录运行 `codex exec resume`；核对本机 help，重新传入已解析配置、日志输出和相应权限。续接不加 `--worktree`，也不用 `--last`。

进程仍在写入时先等待或核实身份后停止；只停止本次任务的进程。缺少会话 ID 时从运行事件定位，不能猜测。

同一启动、认证、连接或进程中断故障允许恢复一次；恢复后仍失败就标记对应任务阻塞，不因换了调用而重置次数。这与业务修复计数分开。进程退出码、事件错误与最终回复一起用于判断调用是否正常结束。

替代调用必须复用已登记现场。未创建成功的首次调用，确认没有遗留进程或 worktree 后才能重试创建；不因工具等待超时重复派工。

中断恢复先核实已完成的提交和发布结果，再续接剩余工作，不重复实现、合并或清理。保留失败输出和进度，返回入口调度。
