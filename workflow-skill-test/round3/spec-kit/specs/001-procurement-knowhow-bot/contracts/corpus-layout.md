# Contract — 语料目录与人员名单约定

> **这一份是写给采购部同事看的**,不是技术文档。请照着摆文件夹就行。

## 一、共享盘上的文件夹长这样

```
采购知识库/                      ← 就是这个文件夹,大家往里丢文件
├── roster.csv                   ← 人员名单(采购负责人维护,见下)
├── 品类管理手册-电解铜.md        ← 普通文件,直接丢在根目录或任意子目录
├── 采购流程说明.docx
├── 供应商清单-电解铜.xlsx
├── 规格要求/                     ← 想怎么分子文件夹都行,不影响权限
│   └── 紧固件规格.md
└── 保密/                        ← ★ 这个文件夹里的东西 = 保密
    ├── 电解铜/                   ← ★ 必须按品类再分一层
    │   ├── 2025年度报价表.xlsx
    │   └── 谈判纪要-2025Q1.docx
    └── 紧固件/
        └── 成本分析.md
```

## 二、三条规矩(只有三条)

1. **保密的东西,放进"保密"文件夹。** 放进去的整个文件都算保密,
   普通采购员一个字都看不到。没放进去的,全部门都能查。
2. **"保密"文件夹里必须再按品类分一层子文件夹。** 因为只有管这个品类的经理才能看。
   文件夹名就写品类名(比如"电解铜"),要和名单里"负责品类"那一列写的一模一样。
3. **万一有保密文件不知道归哪个品类**,就直接丢在"保密"文件夹根目录下。
   这种文件**只有采购负责人本人能看**,谁都别想绕过去。

> ⚠️ 系统**不会**自己去猜哪份文件保密。你不放进"保密"文件夹,它就是公开的。
> 这是需求方明确要求的("猜错一次就是事故")。

## 三、支持哪些文件格式

| 能读 | 读不了(会进"未纳入清单",但不影响其他文件) |
|------|------|
| `.md` `.txt` `.docx` `.pdf` `.xlsx` | 扫描件 PDF(图片,没文字)、加密 PDF、`.doc`(老格式)、`.ppt`、压缩包、损坏文件 |

读不了的文件**不会被偷偷跳过**,可以随时用 `pbot rejected` 看一眼有哪些东西没进来。

## 四、人员名单 `roster.csv`

用 Excel 直接打开编辑就行,四列,存成 CSV:

```csv
工号,姓名,角色,负责品类
P1001,李明,采购员,
P1002,张伟,品类经理,电解铜
P1003,王芳,品类经理,紧固件
P1005,赵强,品类经理,电解铜;铝锭
P9000,陈国华,采购负责人,*
```

| 列 | 怎么填 |
|----|--------|
| 工号 | 不能重复 |
| 姓名 | 转人工时会显示给采购员看 |
| 角色 | 只能填三种之一:`采购员` / `品类经理` / `采购负责人` |
| 负责品类 | 采购员**留空**;品类经理填品类名,管多个用**分号**隔开;采购负责人填一个 `*` |

**几条提醒**

- "负责品类"里写的名字,要和"保密"文件夹下的子文件夹名**完全一致**,否则那个人会看不到。
- 名单填错了(比如角色写成"经理"),系统会**直接报错并告诉你是第几行**,
  不会默默给人降权限——免得将来出现"某某突然查不到东西"的怪事。
- 人事有变动,改这个文件就行,**不用找 IT**。

用 `pbot roster-template > roster.csv` 可以生成一份带表头的空模板
(Excel 打开中文不乱码)。

## 五、加了新文件之后要做什么

跑一次:

```
pbot ingest
```

就这一条命令。之后大家问的问题就能查到新文件了。
