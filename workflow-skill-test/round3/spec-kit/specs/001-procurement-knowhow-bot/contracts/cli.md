# Contract — 命令行接口 (`pbot`)

**通用参数**(所有子命令可用)

| 参数 | 默认 | 说明 |
|------|------|------|
| `--corpus PATH` | `./corpus` | 语料根目录(共享盘上的固定文件夹) |
| `--roster PATH` | `<corpus>/../roster.csv` | 人员名单 |
| `--state PATH` | `./.pbot` | 索引与日志的存放目录 |
| `--secret-dir NAME` | `保密` | 保密文件夹的目录名(可改,便于英文环境) |

**退出码**

| 码 | 含义 |
|----|------|
| 0 | 成功(**包括**"答不上来"与"权限不足"——它们是正常业务结果,不是程序错误) |
| 2 | 用法错误(参数缺失、工号不存在) |
| 3 | 环境错误(语料目录不存在、roster.csv 缺列/角色非法) |
| 4 | 索引缺失(未先执行 `ingest`) |

---

## `pbot ingest`

扫描语料目录,建立索引。

```
pbot ingest [--corpus PATH] [--state PATH] [--secret-dir NAME]
```

**输出**(人读格式):

```
已导入 9 份文档,共 47 个片段。
  普通:6 份    受限:3 份(品类:电解铜 2、紧固件 1)
未纳入知识库 2 个文件:
  - 扫描件-旧合同.pdf        文件损坏或加密,无法读取
  - 说明.bin                 不支持的格式(.bin)
索引已写入 .pbot/index.json
```

**契约**

- C-I1:任何单个文件的解析失败 **MUST NOT** 中断整体导入(FR-018)。
- C-I2:"已导入 + 未纳入" 的文件数 **MUST** 等于语料目录下的普通文件总数(SC-008)。
- C-I3:重复执行幂等(INV-I1)。
- C-I4:受限文档的**文件名不出现**在导入摘要中,只出现计数与品类。

## `pbot ask`

提问。

```
pbot ask "问题" --user 工号 [--driver mock|anthropic] [--top-k N] [--json]
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `--user` | (必填) | 工号,必须存在于 roster |
| `--driver` | `mock` | `mock` = 离线确定性驱动(演示/测试用);`anthropic` = 真实驱动 |
| `--top-k` | `12` | 交给模型的片段数上限 |
| `--json` | off | 输出 `Answer` 的 JSON,供其他渠道消费 |

**输出示例(答上来了)**

```
【答案】
电解铜品类由张伟(工号 P1002)负责。

【出处】
  [1] 品类管理手册-电解铜.md — § 1 品类归属
      "本品类负责人:张伟(工号 P1002),分机 8021。"
```

**输出示例(资料不一致 — FR-005b)**

```
【答案】
资料中有两处关于该流程的说明,内容不一致,请自行核实后再执行。

【来源 A】规格要求-紧固件.md — § 2 表面处理
      "紧固件表面处理采用达克罗。"
【来源 B】规格要求-紧固件-补充.md — § 1 表面处理
      "紧固件表面处理一律采用镀锌钝化。"

⚠ 资料不一致,请自行核实。两份文件均未标注生效日期或版本号,系统不做裁决。
```

**输出示例(有新旧版本 — FR-005a)**

```
【答案】
……(按新版作答)……

【出处】
  [1] 采购流程说明.docx — § 2 审批环节(生效日期 2024-03-01)

ℹ 另有旧版:采购流程说明-2019旧版.docx(生效日期 2019-05-01),本次未采用。
```

**输出示例(答不上来 — FR-003 / FR-014)**

```
【答案】
资料里没有查到相关内容,我不能凭猜测回答。

→ 已转人工:请联系 王芳(工号 P1003,紧固件品类经理)
   本次提问已记入知识缺口清单(编号 a3f91c20d4e1)。
```

**输出示例(权限不足 — FR-010)**

```
【答案】
该问题涉及受限信息,你当前的权限无法查看。

→ 请联系 张伟(工号 P1002,电解铜品类经理)
```

**契约**

- C-A1:`status == answered` 时**必须**有【出处】区块;无出处的答案不允许输出(INV-A1)。
- C-A2:`denied` 的答案正文为**固定常量**,不随命中内容变化(INV-A4)。
- C-A3:`unknown` / `denied` 均返回退出码 **0**。
- C-A4:受限文档的名称、正文、数值 **MUST NOT** 出现在非授权用户的任何输出中。
- C-A5:`--json` 输出为 `Answer` 的 JSON 序列化,字段名与 data-model.md 一致。
- C-A6:当 `partial_context` 为真时,输出末尾追加
  `ℹ 资料较多,本次只参考了其中相关度最高的 N 段。`

## `pbot gaps`

知识缺口清单(FR-015)。

```
pbot gaps [--limit N] [--json]
```

```
知识缺口清单(按被提问次数降序)
次数  最近一次        问题                              建议找谁
  4   2026-07-31     钛合金紧固件的规格要求是什么       王芳(P1003)
  2   2026-07-30     铝锭的年度框架协议怎么走           陈国华(P9000)
```

**契约**:C-G1:同一问题按**归一化文本**(去空白、去标点、小写化)聚合计数。
C-G2:`permission_denied` 类记录**也进清单**但单独分组显示,因为它不是知识缺口
而是权限咨询——混在一起会让品类经理误以为要去补文档。

## `pbot roster-template`

打印一份 `roster.csv` 模板(给需求方填)。

```
pbot roster-template > roster.csv
```

**契约**:C-R1:输出为 **UTF-8 with BOM**,确保 Excel 双击打开中文不乱码(D-10)。
