# 第三轮 REFLECTION.md 升级要求(写进三个 agent 的提示词)

在第一二轮"每阶段记录干扰/清晰"的基础上,第三轮的 REFLECTION.md 增加**心理状态日志**维度,要求诚实到近乎自我暴露:

## 每个阶段除了原有四问,额外记录:
1. **内耗时刻**:这一步有没有出现"反复横跳"——做了又想改、改了又改回来、在两个方案间来回摇摆、写完推翻重写?具体是什么引发的(工作流规则?模糊需求?自我怀疑?)每次内耗大约消耗了多少轮思考/多少工具调用。
2. **规则与判断的拉扯**:有没有"工作流让我这么做,但我觉得没必要/不对"的时刻?你最终服从了还是变通了?服从的时候心里服气吗?
3. **模糊需求带来的感受**:面对口语化、留白很多的用户需求,你是感到"自由、可以发挥",还是"焦虑、怕做错方向"?工作流此刻是缓解了这种感受还是放大了?
4. **状态曲线**:用一个词描述此阶段的整体状态(如:顺滑/胶着/空转/亢奋/麻木/如释重负)。

## 最终总结新增:
- **内耗指数 1-10**(10=严重内耗,大量时间花在反复与自我怀疑上)+ 内耗的前三大来源排名
- **一段"如果没有这个工作流,我会怎么做这个任务"的反事实自述**——并诚实评估那样做的结果会更好还是更差
- **一句话回答:遵照这套提示词/工作流走下来,总体感觉像什么?**(允许用比喻,要求诚实,不讨好)

注意:心理状态日志必须在过程中随手记,不许最后补写(补写的会平滑掉真实的反复)。
