# 真实 LLM 调用置于 LlmDriver 之后,测试永不触网

这是一条环境约束,在代码里看不出来:**本项目的测试必须全部离线可跑**。真实的模型调用要写,但不允许在测试中被执行。

因此全部模型调用收束到一个只有一个方法的接口 `LlmDriver.complete(prompt) -> str`。`AnthropicDriver` 是真实实现,**写了但从不在测试里跑**;`ScriptedDriver` 按预设脚本返回,测试全部用它。系统其余部分对"背后是哪个驱动"一无所知。

## Consequences

未来的读者会发现这个项目**没有一个集成测试真的调用过模型** —— 这是刻意的,不是遗漏,不需要"补上"。相应地,真实驱动的正确性(鉴权、重试、解析)不由测试保证,而由它极小的体积保证:它只做一件事,把字符串换成字符串。

同时这一层顺手买到了别的东西:摄取时生成摘要、提问时选材、提问时作答,三处都走同一个接口,所以整条主流程 —— 包括那些跨越两次模型调用的路径 —— 都能在测试里被确定性地驱动。
