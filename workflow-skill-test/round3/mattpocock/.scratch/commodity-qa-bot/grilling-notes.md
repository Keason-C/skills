## 二、技术决策(工程师自答)

### T1. 不用向量库,那怎么"直接给模型看"?

**问**:几十份 Word/PDF/Excel 全文塞进一次请求,可行吗?
**答**:大概率不可行,而且贵。几十份采购文档的正文很容易到几十万 token,每问一次全量重读一遍,延迟和成本都不可接受;文档再长一点直接超窗。
**决策**:**两段式选材(manifest-first)**。
1. 摄取时为每份知识文档生成一条**目录条目**(标题、品类、一句话摘要、保密标记、字数)。所有条目合起来是一份很小的**知识目录**。
2. 提问时先把知识目录(小)交给模型,让它挑出相关的 N 份(默认 4 份)。
3. 再把这 N 份的**全文**交给模型作答。

这仍然是"直接给模型看",没有向量、没有 embedding、没有额外数据库 —— 只是先看目录再看正文,和人找资料的顺序一样。语料整体很小时(低于预算)退化为"全塞",行为一致。
**→ 值得写 ADR**(会被问"为什么不上 RAG")。

### T2. 权限怎么落地?能不能靠提示词让模型别说?

**答:绝对不能。** 靠"系统提示词里写着别告诉他"来保密,等于把保密内容送到模型面前再祈祷它守口如瓶 —— 一次越狱、一次提示词注入、一次模型抽风就泄露。
**决策**:**过滤发生在模型之前**。按提问人角色裁剪语料,保密内容在进入请求之前就被剔除;采购员的那次请求里,报价文字根本不存在。这是本系统唯一的安全边界,必须有测试直接钉死"渲染给模型的 prompt 里不含保密串"。
**→ 必须写 ADR。**

### T3. 权限拦下来之后,机器人说什么?

**答**:不能装作不知道 —— 那和"库里没有"混为一谈,既误导提问人,又污染知识缺口统计。
**决策**:**明说但不透露** —— "这个问题涉及保密内容(报价/成本/谈判策略),你的权限看不到,已转给 <品类经理>"。承认存在,不泄露内容。是否可接受属于业主的信息安全政策,进提问清单(Q2 附带)。

### T4. 怎么保证"别瞎编"?

**答**:光在提示词里写"不要编造"是没用的,必须有机械校验。
**决策**:三道闸,全部离线可测:
1. 模型**必须返回结构化结果**:`{ answer, citations[], abstained, reason }`,每条 citation 指向 `document_id` + 原文片段。
2. **出处校验**:每条 citation 的 `document_id` 必须在本次真正喂给模型的文档集合里;引用片段必须**逐字出现**在该文档正文中(规范化空白后的子串匹配)。
3. 校验不过 → **强制降级为弃答** + 转人工。宁可不答,不可错答。

"答不上来老实说不知道"因此不是一句提示词,而是一个**默认路径**:一切异常(模型输出不合法、引用对不上、超时、驱动报错)都收敛到弃答。
**→ 值得写 ADR。**

### T5. 真实 LLM 调用怎么放?

**决策**:`LlmDriver` 协议,只有一个方法(输入 prompt,输出文本)。
- `AnthropicDriver` — 真实实现,**写但不在测试中跑**。
- `ScriptedDriver` — 确定性假驱动,按预设脚本返回,测试全用它。
系统其余部分对"哪个驱动"一无所知。
**→ 值得写 ADR**(未来读者会问为什么绕这一层)。

### T6. 以后要接企业微信,现在怎么留口子?

**决策**:核心是一个深模块:`answer(question, asker) -> Answer`,不知道 CLI 的存在,不打印任何东西,不读 `sys.argv`。CLI 只是它的第一个前端;企业微信以后是第二个。不为企业微信预留任何具体代码,只保证核心不被 CLI 污染。

### T7. 读不懂的文件怎么办?

**决策**:**绝不静默跳过**。摄取产出一份**摄取报告**:成功 N 份、跳过 M 份并逐个列出原因(格式不支持 / 加密 / 空 / 疑似扫描件无文字层)。"大家交上来什么算什么"的现实里,静默丢文件等于知识黑洞,和项目目的正相反。

### T8. 分类/摘要谁来做?没人标怎么办?

**决策**:三级取值,**保密标记 fail-safe**:
1. 文件旁的元数据文件(`<文件名>.meta.yaml`)显式声明 → 用它。
2. 否则按目录约定(如放在 `保密/` 下)→ 整份保密。
3. 都没有 → 品类="未分类";**保密标记默认取"保密"还是"不保密",是业主的风险偏好,进提问清单(Q2)**。工程上我推荐默认"保密"(宁可挡住也不泄露),但这会让没人标的文档对采购员全体不可见,是个真实代价,必须业主知情。

摘要在摄取时由驱动生成(走同一个 `LlmDriver`,测试里用假驱动)。

### T9. CLI 长什么样?

`ingest`(建知识目录+摄取报告)、`ask`(提问)、`gaps`(知识缺口清单)、`audit`(访问记录)、`doctor`(列读不了的文件)。

### T10. 语言?

中文。文档中文、提问中文、回答中文、术语按 `CONTEXT.md`。
