# 01 — 读得进来,读不进的说清楚

**What to build:** 把一个知识库根目录交给系统,它走一遍全部文件,把 `.docx` `.pdf` `.xlsx` `.md` `.txt` 的正文读出来,建立**知识目录**(每份一条:标题、品类、是否保密、生效日期、字数),并产出**摄取报告**:读进去了几份、没读进去几份、每一份没读进去的都写明原因(格式不支持 / 疑似扫描件 / 空文件 / 读取失败)。命令行 `ingest` 能把这份报告打出来给采购负责人看。

保密判定只看文档在不在**保密文件夹**下(ADR-0005)。品类从目录名推断。生效日期从正文抽取,支持 `2024-01-01`、`2024年1月1日`、`2024/01/01`。此时**还没有摘要**,摘要是 03 的事。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 五种支持格式各能抽出正文,测试用现场生成的真实二进制文件(不入库)
- [ ] 不支持的扩展名进入摄取报告的"未读入",带原因,**绝不静默跳过**
- [ ] 无文字层的 PDF 被标记为疑似扫描件,单独成组
- [ ] 保密文件夹下的文档 `restricted=True`,其余 `False`
- [ ] 正文里的生效日期被抽出;没有日期的条目该字段为空而不是报错
- [ ] `ingest` 命令打印摄取报告,退出码 0
