# 05 — 问一个能答上来的问题

**What to build:** 采购员用工号提问,拿到一段带**出处**的中文回答。内部走两段式(ADR-0001):第一次调驱动拿知识目录选出最多 4 份文档,第二次调驱动拿这几份的正文作答,模型返回结构化结果。每条出处都被**逐字核回原文**(规范化空白后子串匹配),核得上才给答案(ADR-0003)。命令行 `ask --as <工号> "<问题>"` 打印回答和出处。

核心接口 `answer_question(问题, 提问人, 知识库, 驱动)` **不打印任何东西、不读 argv、不知道 CLI 存在** —— 以后接企业微信靠的就是这一点。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 能答的问题返回回答文本 + 至少一条出处,出处指向真实文档
- [ ] 第二段 prompt 里只含被选中文档的正文,没被选中的不在里面
- [ ] 选材阶段的 prompt 里只有知识目录(标题/品类/摘要),没有正文
- [ ] 出处的引文确实逐字出现在被引文档正文中
- [ ] `ask` 命令打印回答与出处,退出码 0
