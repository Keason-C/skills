# 04 — 谁能看见什么

**What to build:** 给定知识目录和提问人,算出**可见性划分**:这个人能看的文档、被挡下的文档。采购员看不到任何保密文档;品类经理只看得到**自己负责品类**的保密文档,别的品类的保密文档照样被挡(管金属的查不了包材的报价)。这是系统唯一的安全边界(ADR-0002),是纯函数,不碰模型、不碰文件系统。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 采购员的可见集合里没有任何 `restricted=True` 的文档
- [ ] 品类经理能看到自己品类的保密文档
- [ ] 品类经理**看不到**别的品类的保密文档
- [ ] 公开文档对所有角色都可见,与品类无关
- [ ] 被挡下的文档以独立集合返回(供 07 判断要不要提示"涉及保密"),不与可见集合混淆
