# 09 — 知识缺口清单与访问记录

**What to build:** 每一次弃答记一条**知识缺口**(问题、品类、提问人、时间、转给谁);每一次提问记一条访问记录,尤其标出访问了保密文档的那些。命令行 `gaps` 按品类分组打印缺口清单 —— 这是交给领导的第二产物:它自动指出库里缺哪块、该催谁补。`audit` 打印访问记录。全部只写本地文件。

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] 弃答产生一条知识缺口记录;成功作答不产生
- [ ] `gaps` 按品类分组打印,同一问题重复出现能看出次数
- [ ] 每次提问产生一条访问记录,含提问人、时间、是否触及保密
- [ ] 记录追加写、不覆盖;文件不存在时自动创建
- [ ] 记录只落本地,不发往任何外部
