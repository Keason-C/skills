# 07 — 碰到保密内容:明说,但不透露

**What to build:** 采购员问到保密内容时,不能装作库里没有(会误导人、弄脏知识缺口统计),要明确说"该问题涉及保密内容,你的权限看不到,已转给张三"。判断"这个问题是不是碰到了被挡下的文档"必须**在进程内完成、不经过模型**(ADR-0002 次生):拿问题与被挡下文档的"标题+品类"做字符二元组重合度计算,或问题命中保密话题词。命中就附提示并转人工。提示和回答**可以同时出现**(部分能答、部分涉密)。

**Blocked by:** 04, 06

**Status:** ready-for-agent

- [ ] 采购员问报价类问题 → 回答里出现保密提示,并指出该找谁
- [ ] 保密提示出现时,**发给驱动的任何 prompt 里都不含被挡下文档的正文、摘要或标题**(直接断言 prompt 字符串)
- [ ] 问题与被挡下文档无关时,不出现保密提示(不能见谁都喊"涉及保密")
- [ ] 品类经理问自己品类的保密问题 → 正常作答,无提示
- [ ] 能答的部分照答,保密提示作为附加而非替代
