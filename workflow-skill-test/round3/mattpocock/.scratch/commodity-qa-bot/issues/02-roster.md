# 02 — 认人

**What to build:** 采购负责人维护一张**人员名单**(工号/姓名/角色/负责品类/联系方式),CSV 或 XLSX 都能填。系统按工号查出**提问人**,知道他是采购员还是品类经理、负责哪些品类。命令行 `whoami --as <工号>` 能把这个人的角色和负责品类打出来。名单里还指定一个**兜底接收人**。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 同一个接口能读 CSV 和 XLSX,结果一致
- [ ] 按工号查得到提问人;查不到时给出明确错误而不是当成采购员放行
- [ ] 一个人可以负责多个品类(单元格内分隔)
- [ ] 角色只认"采购员"和"品类经理",其它值报错
- [ ] `whoami` 打印姓名、角色、负责品类
