# 08 — 新旧说法打架时,并排摆出来

**What to build:** 喂给模型的文档按**生效日期倒序**排列,没写日期的按摄取时间兜底排在后面;prompt 明确要求"若多份文档说法不一致,并排列出两个说法并标注各自日期,不要替用户裁决"。采购员因此拿到的默认是较新的说法,而冲突是被展示的、不是被隐藏的。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 有生效日期的文档排在无日期文档之前,日期新的在前
- [ ] 作答 prompt 中每份文档都带着它的生效日期
- [ ] 作答 prompt 含"不要替用户裁决、并排列出并标日期"的指令
- [ ] 两份文档都被引用时,两条出处都通过逐字核验
