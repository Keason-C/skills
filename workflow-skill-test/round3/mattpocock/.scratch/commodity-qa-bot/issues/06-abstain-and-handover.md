# 06 — 答不上来就老实说,并转人工

**What to build:** 一切异常收敛到**弃答**(ADR-0003):驱动报错、返回的不是合法 JSON、字段缺失、模型自称答不了、出处为空、出处的文档 id 不在本次喂进去的集合里、引文在原文里对不上、根本没有可见文档 —— 全部产出"我不知道" + **转人工**,而不是猜。转人工指向该品类的品类经理;品类无人认领时指向**兜底接收人**。提问人看得到该找谁(姓名 + 联系方式)。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 模型返回非法 JSON → 弃答,不抛异常给用户
- [ ] 模型编造了一条不存在的文档 id → 整条回答作废 → 弃答
- [ ] 模型的引文与原文对不上(哪怕只差几个字)→ 整条回答作废 → 弃答
- [ ] 驱动抛异常 → 弃答
- [ ] 没有任何可见文档 → 弃答
- [ ] 每次弃答都带转人工目标;品类无人认领时落到兜底接收人
