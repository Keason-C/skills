# 采购品类知识问答(Commodity Know-How QA)

采购部的知识问答系统。把散落在文档里、以及老采购脑子里的品类知识,变成一个可以提问的库 —— 新人问得到,老人走了留得下。

## Language

### 人与权限

**采购员**:
提问的人的默认角色,只能看到非保密知识。
_Avoid_: 用户, 采购人员, 普通用户, buyer

**品类经理**:
对某个或某几个品类负责的人,是唯一能看到该品类保密知识的角色,也是转人工的默认接收人。
_Avoid_: 经理, 主管, 负责人, owner

**提问人**:
发起一次提问的具体的人,携带其角色与所属品类。识别提问人是回答之前必须完成的一步。
_Avoid_: 调用方, session, 用户身份

### 知识

**品类**:
采购按物料划分的管理单元(如金属、包材、电子件),是知识归属、权限归属和转人工归属的共同主键。
_Avoid_: 类别, 物料组, category, commodity

**知识文档**:
同事上传的一份原始文件,格式不限(Word/PDF/Excel/Markdown 及其它)。系统只读它,不修改它。
_Avoid_: 资料, 语料, 文件, 素材

**保密文件夹**:
知识库里被指定为存放保密内容的目录。**一份知识文档保密与否,只看它在不在保密文件夹里** —— 没有第二个判据,没有段落级例外。
_Avoid_: 涉密目录, 受限目录, restricted dir

**保密知识**:
放在保密文件夹里的整份知识文档,只有对应品类的品类经理能看到。混写了公开内容的文档整份从严。
_Avoid_: 敏感信息, 机密, 涉密数据, secret

**知识目录**:
每份知识文档一条的清单(标题、品类、一句话摘要、生效日期、是否保密),全部合起来仍然很小。系统靠它决定一次提问该翻开哪几份文档的正文。
_Avoid_: 索引, 清单, manifest, index

**摄取报告**:
一次摄取之后产出的对账单:读进去了哪些、没读进去哪些、各自因为什么。没读进去的文件必须逐个列名,不许静默丢弃。
_Avoid_: 日志, 导入结果, 统计

**人员名单**:
由采购负责人维护的一张表(工号/姓名/角色/负责品类),是系统判断提问人是谁、能看什么、转给谁的唯一依据。
_Avoid_: 用户表, 权限表, 通讯录, roster

**知识缺口**:
一次提问没能从库里得到答案,从而暴露出的"库里缺这块知识"的记录。它是本系统交付给领导的第二产物。
_Avoid_: 未回答问题, 失败日志, miss

### 回答

**弃答**:
系统明确说"我不知道"并交出问题,而不是猜。弃答是一种正确的结果,不是失败。
_Avoid_: 拒答, 兜底, 无法回答, fallback

**出处**:
一条回答里指向具体知识文档具体位置的引用。没有出处的回答不允许送到提问人面前。
_Avoid_: 引用, 来源, 参考, citation

**转人工**:
弃答或触碰权限边界之后,把问题连同上下文交给一个具体的人:该品类的品类经理;该品类无人认领时交给**兜底接收人**(采购负责人本人)。
_Avoid_: 升级, 转接, 人工介入, escalation
